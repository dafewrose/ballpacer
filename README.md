# 课包打卡（BallPacer）

一个只做一件事的小 App：**帮你把「30 节课」这种课程包，变成系统日历里每天都会响的提醒，并在打满次数后自动从日历里消失。**

## 它是怎么工作的

系统的日历有一个坑：「重复 30 次」是按**日历走到第 30 天**算的，不是按你**真的去了 30 次**算。你连着几天没去，它照样消耗一次，结果课没上完，提醒先没了。

这个 App 把两件事拆开：

| 谁 | 负责什么 |
|---|---|
| **系统日历** | 提醒。事件的规则是「每天重复、永不终止」，所以哪怕你一个月没去，每天照样响，后台也不会被杀 |
| **这个 App** | 数数。你每打一次卡，它就把日历事件的标题改成「🏀 篮球课 · 已完成 7/30」 |

当你打满第 30 次，**App 会把那条日历事件直接删掉**——日历里彻底消失，不会再响。

## 三步拿到 APK

### 第 1 步：建一个 GitHub 仓库

1. 打开 <https://github.com> 注册 / 登录
2. 右上角 `+` → `New repository`
3. `Repository name` 随便填，比如 `ballpacer`
4. **选 `Public`**（公开仓库的安装包可以直接下载，不用登录；选 Private 也行，只是下载时要登录）
5. 不要勾任何 `Add a README file` 之类的选项，直接点 **`Create repository`**

### 第 2 步：把本文件夹里的所有东西传上去

在新建好的空仓库页面，点 **`uploading an existing file`**（或者 `Add file` → `Upload files`）。

然后把本文件夹里的**所有文件和文件夹**拖进去（注意：是文件夹里的东西，不是文件夹本身）：

```
.github/            ← 必须有，自动编译全靠它
app/
build.gradle
gradle.properties
settings.gradle
.gitignore
README.md
```

> 拖拽时 `.github` 这个以点开头的文件夹有可能被系统隐藏。如果 Mac/Windows 资源管理器里看不到它：
> - Windows：资源管理器 → 查看 → 勾选「隐藏的项目」
> - 如果实在传不上，也可以在 GitHub 网页上点 `Add file` → `Create new file`，文件名输入 `.github/workflows/build.yml`（斜杠会自动建目录），再把内容粘进去。

传完点绿色的 **`Commit changes`**。

### 第 3 步：等 3 分钟，下载 APK

1. 点仓库顶部的 **`Actions`** 标签
2. 如果提示要启用，点 **`I understand my workflows, go ahead and enable them`**
3. 你会看到一条正在跑的 `build-apk`，黄色的点 = 正在编译（约 2–4 分钟）
4. 变成**绿色对勾**后，点进这次运行：
   - **方式一（推荐）**：回到仓库首页 → 右侧 **`Releases`** → 点最新的一条 → 下载 `app-debug.apk`
   - **方式二**：在运行详情页最下面的 `Artifacts` 里下载 `ballpacer-apk.zip`，解压得到 `app-debug.apk`

## 装到手机上

1. 把 `app-debug.apk` 传到手机（微信传文件、QQ、数据线都行）
2. 手机上点这个文件安装。vivo 会拦一下：
   - 提示「禁止安装未知来源应用」→ 点**设置** → 允许这个来源安装
   - 如果开了「纯净模式」→ 设置里搜「纯净模式」→ 临时关闭，装完可以再打开
3. 第一次打开，App 会申请**日历权限**，必须点「允许」
4. 然后它会自动在系统日历里创建那条每天提醒的事件

## 用起来

- **打卡 +1**：去了一次就点一下，进度 `7/30` 会同步到日历事件标题上
- **撤销一次**：点错了可以回退
- **重建提醒**：如果你在日历里手动删了那条事件，点这个重新创建
- **设置**：改课程名（默认「🏀 篮球课」）、改总次数（默认 30）、改每天的提醒时间（默认 18:30）、选择写入哪个日历账户
- **查看日历**：跳转到系统日历，确认事件真的在
- **重新开始（清零）**：进度归零并重建事件，开启下一轮

打满次数后，卡片会显示「全部 30 次已完成」，日历里那条事件已经自动删掉了。

## 常见问题

**编译失败怎么办？**
点进红色的 ❌ 运行记录，找到报错的那一行（通常是 `error:` 开头），把内容发我，我改代码。

**日历里没看到事件？**
点 App 里的「查看日历」应该能跳到今天；如果日历里筛选了「只看某些账户」，把对应的账户勾上。设置里可以换一个日历账户重新写入。

**提醒不响 / 响得不准？**
提醒是系统日历发的，去手机「设置 → 日历 → 通知」确认日历通知是开着的。这个 App 本身不需要后台保活，因为它不发通知。

**换手机 / 重装 App 数据会不会丢？**
打卡进度存在 App 本地，卸载就没了。但**日历里的事件还在**（提醒照样会响），重装后点「重建提醒」会以进度 0 重新开始，然后是重复事件，建议先在旧手机上点「重新开始」。

**想彻底不要了？**
先在 App 里点「重新开始」（会删掉日历事件并重建），再卸载 App；或者卸载后到系统日历里搜索「篮球课」，把那条每天重复的事件删掉。**只卸载不清理的话，那条日历事件会一直留在日历里每天响。**

## 技术说明

- 纯 Java，零第三方依赖，只用 Android 系统的 `CalendarContract` 接口读写日历
- `minSdk 24`（Android 7.0 起），`targetSdk 34`
- APK 约 1–2 MB
- 只用两个权限：`READ_CALENDAR`、`WRITE_CALENDAR`
