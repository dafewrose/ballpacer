# 打卡管家（BallPacer v2）

两种打卡模式 + 通知栏常驻卡片 + 留言 + 月历回看。数据全部存在手机本地，不联网。

## 两种打卡模式

**周期打卡**
适合「练琴」「健身房」这类固定节奏的事。可以选每周哪几天（周一/周三/周五），也可以改成「每月 1 号、15 号」。到日子就会提醒。

**数量打卡**
适合「30 节课包」这种一次性的。设一个总次数，**每天都会提醒你一次，只有真正打卡了才会推进**；中间连着几天没去，提醒也不会断。打满次数后，卡片和通知会自动消失。

> 这就是关键区别：系统日历的「重复 30 次」是按天数算的，你没去也照扣；这里是按**你真的去打了卡**算。

## 提醒怎么设（每个事项独立）

新建或编辑时有三项：

| 设置 | 说明 |
|---|---|
| **哪天** | 周期型选每周几（可多选，比如周二、周四）或每月几号；数量型是每天 |
| **几点** | 到点提醒的时间，比如「周二 20:00」 |
| **提前多久** | 不提前 / 5 / 10 / 15 / 30 / 60 分钟。提前那次会**横幅 + 声音弹出来**，到点再弹一次 |

两条提醒都会带一个 **「✓ 打卡」** 按钮，不用打开 App 就能点。
**已经打过卡的那天，两条提醒都不会再响**（只有通知栏卡片更新成「今天已打卡」）。

> 例如：设「睡觉 · 每周二 · 20:00 · 提前 30 分钟」，那你每周二 19:30 会收到「还有 30 分钟就要开始了」，20:00 再收到「该打卡了」。

## 通知的两种形态

| 形态 | 长什么样 | 会不会响 |
|---|---|---|
| **常驻卡片** | 通知栏里一直有一张，写着今天还剩几次 | 不响，安静待着 |
| **提醒通知** | 提前和到点时弹出横幅 | 会响 + 震动，带「✓ 打卡」按钮 |

两个用的是不同的通知通道，可以分别控制：系统设置里能单独关掉其中一个，或者把「打卡提醒」设成静音（会弹但不响）。

## 怎么用

| 动作 | 怎么做 |
|---|---|
| 新建打卡 | 右下角 **＋** → 起名字 → 选模式 → 设提醒时间 → 保存 |
| 打卡 | 首页卡片右侧的 **圆圈按钮**，或通知栏卡片上的 **「✓ 打卡」** |
| 写留言 | 打卡后会自动弹出留言框，可以写「练了 40 分钟，手感不错」，也能点「跳过」 |
| 撤回 | 点卡片进详情 → **撤回最近一次**（会确认一次，防误触） |
| 看历史 | 点卡片进详情 → 月历上**有绿点的日子**就是打卡过的，点某一天只看那天的记录和留言 |
| 改设置 | 详情里 **编辑**；想删掉整个打卡事项用 **删除这个打卡** |

同一天同一个事项**只能打一次卡**，重复点会提示你，避免误触。

## 通知栏卡片

每个打卡事项在通知栏有一张常驻卡片，写着：
- 事项名称
- 「今天还没打卡 · 还剩 12 次 · 2026-10-22」
- 一个 **「✓ 打卡」** 按钮

点 ✓ 会直接记下今天的打卡，然后跳到 App 里弹出留言框。
点卡片本身会跳到这个事项的详情页。

**关于可靠性的实话：** Android 14 之后系统允许用户划掉「常驻」通知，vivo 的省电策略也可能折叠通知。如果发现卡片不见了，打开一次 App 就会重新生成；想让它更稳，去系统设置里给「打卡管家」打开 **通知权限 / 自启动 / 后台高耗电允许**。

## 数据存在哪

`/data/data/com.dafeiyu.ballpacer/databases/ballpacer.db`，App 私有目录，卸载即删，不上传任何地方。
**换手机不会自动同步**（本地存储的代价），需要的话我可以加「导出备份」。

## 更新到 v2（你已经有仓库了）

1. 打开你的仓库 `https://github.com/你的用户名/ballpacer`
2. **`Add file`** → **`Upload files`**
3. 把解压出来的 **`app` 整个文件夹**拖进去（GitHub 会自动新增文件、覆盖改动的文件）
4. 滚到底部点 **`Commit changes`**
5. 去 **`Actions`** 等 3 分钟变绿
6. 到 **`Releases`** 下载新的 `app-debug.apk`，覆盖安装

**⚠️ 装之前先做一件事：** v1 在系统日历里建过一条「🏀 篮球课」的每日事件，新版本不再用它了。到系统日历里搜索「篮球课」，把那条每天重复的事件**删掉**，否则它会和新版的通知一起响、造成重复提醒。

## 技术说明

- 纯 Java + 系统原生 API，**零第三方依赖**（网络请求都没有）
- 界面是本地 `assets/index.html`，用 WebView 渲染；WebView 在 `onDestroy` 里显式销毁、移除 JS 接口，避免内存泄漏
- 数据库单例只持有 Application 上下文，不持有 Activity
- 权限只有两个：通知、开机自启（用于重新登记每日提醒）

## 常见问题

**通知不响 / 卡片被清掉**
系统设置 → 应用 → 打卡管家 → 允许通知；再把「自启动」「后台高耗电」打开。vivo 的 i管家 里也要放行。

**提醒时间不准（差几分钟）**
用的是省电友好的非精确闹钟，避免被系统拒绝。状态栏提醒可能晚几分钟，属于正常。

**装不上**
先卸载旧版再装，或者确认「纯净模式」已临时关闭。
